# Verilog Basics

This section contains my solutions to the **HDLBits Basic** problems along with the approaches I used to solve them.

## Before You Start

I recommend learning the fundamentals of Verilog before attempting these exercises. HDLBits is designed for practice, not for teaching the language from scratch.

Before solving these problems, you should be familiar with:

* Basic Verilog syntax
* Modules and ports
* Wire and reg (or logic in SystemVerilog)
* Continuous assignments (`assign`)
* Basic procedural blocks (`always`)
* Common operators

You can learn these concepts from any good resource, whether it's a textbook, online tutorials, YouTube, or an AI assistant.

## How to Use This Repository

1. Attempt each HDLBits problem on your own.
2. If you're stuck, spend some time debugging your solution first.
3. Only then compare your solution with mine.
4. Read the explanation to understand **why** the solution works instead of simply copying the code.

The goal of this repository is not to provide answers, but to document my learning process and hopefully help others understand the reasoning behind each solution.
