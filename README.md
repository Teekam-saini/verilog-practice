# Verilog Practice

This repository is dedicated to practicing and improving my Verilog design skills. It is separate from my **rtl-design-verilog** repository, which contains my Verilog projects and documents my overall RTL design journey.

This repository is organized into three directories:

## 1. `hdlbits/`

Contains my HDLBits solutions and tracks my progress while solving HDLBits problems. The goal is to improve my RTL design and problem-solving skills through consistent practice.

## 2. `personal/`

Contains Verilog problems that I create or find from other sources. These are independent of HDLBits and are used to challenge myself with additional design exercises.

## 3. `docs/`

Contains notes, references, and useful concepts that I want to keep for future study while learning Verilog and digital design.

---

This repository focuses on practice and learning. Larger Verilog projects are maintained in my **rtl-design-verilog** repository.
